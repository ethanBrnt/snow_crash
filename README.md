# Snow Crash — Audit Système & Élévation de Privilèges

Introduction pratique à la sécurité des systèmes Unix/Linux à travers une série de scénarios d'audit, de reverse engineering et d'élévation de privilèges.

### Domaines couverts
- **Audit de configuration Linux :** recherche de fichiers sensibles, permissions mal configurées (`SUID`/`SGID`), tâches planifiées (`cron`) et détournement de variables d'environnement (`PATH`, `LD_PRELOAD`).
- **Analyse de code & binaires :** rétro-ingénierie de scripts Shell, Perl, PHP et d'exécutables C pour identifier des failles d'injection de commandes ou de logique.
- **Réseau & Cryptographie basique :** capture et analyse de trafic réseau, décodage et analyse de mécanismes d'authentification faibles.
